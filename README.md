文件粉碎工具 crush.exe  使用说明
================================

一、两种用法
  1) 命令行:  在 cmd 里运行  crush.exe <目标目录> [选项]
  2) 双击:    把 crush.exe 和 粉碎当前目录.cmd 放到你要清空的那个文件夹里,
             双击 粉碎当前目录.cmd , 输入大写 YES 确认。
             (注意: 该文件夹内的 crush.exe 与 .cmd 因正被运行而无法删除, 属正常现象)

二、命令格式
  crush.exe <目标目录> [/*.后缀 ...] [/*!*后缀 ...] [/cmd] [/y]

  <目标目录>    必填。要递归粉碎的目录(可相对路径)。不存在或非目录会报错。
  /*.ext        白名单: 只删这些扩展名。可多次写, 也可逗号合并, 如 /*.txt,log
                省略白名单 = 删除目录内全部文件。
  /*!*.ext      黑名单: 排除这些扩展名(不删)。可多次/逗号。
                同一扩展名同时出现在白、黑名单 => 直接报错退出。
  /cmd          改用外部命令: 删除用 del /f /q , 结束进程用 taskkill /f /im
                (默认用 Win32 API: DeleteFileW + TerminateProcess, 更快更稳)
  /y            跳过二次确认(默认必须输入大写 YES)
  -h / --help   查看帮助(也可用 /?)

  说明: 扩展名写 .txt 或 txt 都行, 大小写不敏感。

三、它做什么(循环直到目录内不剩匹配文件)
  每一轮:
    1. 递归扫描目录, 按白/黑名单筛选要删的文件;
    2. 先删除没有被占用的文件;
    3. 对删不掉的文件, 用「系统重启管理器(RM)+模块快照」精确定位正在占用它的进程,
       然后强制结束这些进程(只结束真正占用的, 不会乱杀无关进程);
    4. 进入下一轮, 此时上一步解开的文件即可删除;
    5. 直到没有匹配文件, 或一轮下来既删不掉也找不到可结束的占用进程则停止。

四、进度与汇报
  - 每轮显示进度条 [####....] 百分比 (已处理/总数)。
  - 每轮汇报: 删除了哪些文件、结束了哪些占用进程、哪些无法处理。
  - 删除清单按文件体积从大到小排序; 超过 10 个时只列最大的 10 个并加「等」。
    结束的进程同理: 超过 10 个列前 10 个 PID/名称并加「等」。

五、示例
  crush.exe D:\temp /*.tmp,log /y
  crush.exe D:\temp /*!*.keep
  crush.exe E:\cache
  crush.exe E:\cache /cmd

六、退出码
  0 = 目标内匹配文件已全部删除
  1 = 仍有无法删除的剩余文件(通常是系统保护、且无法结束其占用进程的文件)
  2 = 参数错误     3 = 用户取消了确认

七、安全提醒
  这是不可恢复的物理删除工具, 请谨慎核对 <目标目录> 后再输入 YES。
  默认不跳过确认; 脚本/批处理里可用 /y。
